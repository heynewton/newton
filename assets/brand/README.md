# Brand assets

The Hey Newton logo, called the "talking sail": a speech bubble with a sailboat flying a
spinnaker inside it. It stands for both halves of Newton, the voice assistant and the boat.

| File | Use |
| --- | --- |
| `icon.svg` | Primary mark: app icon, social avatar, anything 96 px and up |
| `icon-small.svg` | 32 to 96 px: drops the spinnaker seam, thicker mast |
| `favicon.svg` | Under 32 px: sails and hull only (also used as `apps/web/src/app/icon.svg`) |
| `mark-light.svg` | Bubble without the tile, for light backgrounds (navy outline) |
| `mark-dark.svg` | Bubble without the tile, for dark backgrounds |
| `mark-mono.svg` | One colour, bubble with the boat knocked out. Uses `currentColor` |
| `icon-mono.svg` | One colour, tile with the bubble knocked out. Uses `currentColor` |

The monochrome files take the colour of the surrounding text when inlined, and render black
when used as a plain image. Use them for print, embossing, stamps and single-colour contexts.

## Colours

| Name | Hex | Used for |
| --- | --- | --- |
| Navy | `#0B2545` | Tile, hull, mast |
| Teal | `#13A89E` | Mainsail |
| Spinnaker orange | `#F2A541` | Spinnaker |
| White | `#FFFFFF` | Speech bubble |

All files are drawn on the same 180 × 180 grid, so shapes line up between versions.
